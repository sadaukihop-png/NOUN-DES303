# DES303 Group Registration & Payment Tracking System

**Live Demo:** https://des303-group-registration.netlify.app/

## Overview
This is a real-time web application for student group registration and payment management at NOUN Abuja Model Study Centre.

## Key Features
- **Self-Registration** – Students register with their name and matriculation number
- **Role-Based Access** – Guest, Member, Group Leader, and Admin interfaces
- **Real-Time Database** – Firebase Realtime Database for instant sync
- **Group Management** – Admin creates groups and generates leader passwords
- **Payment Tracking** – Leaders confirm and manage member payments
- **Feedback System** – Users can send suggestions directly from the app

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** Firebase Realtime Database
- **Hosting:** Netlify
